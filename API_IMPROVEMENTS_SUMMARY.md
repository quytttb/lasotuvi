# Lưu trữ hiện đại hóa API

[English version](API_IMPROVEMENTS_SUMMARY.en.md)

Bản tóm tắt triển khai năm 2025 ban đầu đề cập đến các module đã bị loại bỏ, frontend Next.js dự kiến và số liệu kiểm thử/coverage lịch sử. Tài liệu này được giữ lại dưới dạng ghi chú ngắn để các thông tin đó không bị hiểu là trạng thái hiện tại của dự án.

API đang hoạt động là v2 với khóa JSON tiếng Anh. Xem thiết lập, endpoint và vận hành hiện tại tại [README](README.md) và [tài liệu API](API_README.md); công việc hiện tại tại [lộ trình](TODO.md); trạng thái tự động tại `.github/workflows/ci.yml`.
