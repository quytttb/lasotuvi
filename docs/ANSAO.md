# An sao / Star placement

## Tiếng Việt

Tài liệu quy tắc an sao đang được biên soạn. Mỗi quy tắc bổ sung cần nêu rõ nguồn tham chiếu, điều kiện đầu vào, thứ tự áp dụng và ca kiểm thử xác nhận để tránh thay đổi ngoài ý muốn trong logic domain.

Thuật ngữ chuẩn xem tại [Thuật ngữ](TERMINOLOGY.md); quy ước identifier xem tại [Quy ước đặt tên](NAMING.md).

---

## English

The star-placement rule documentation is being prepared. Each new rule must identify its source, inputs, application order, and validating test case to prevent unintended domain-logic changes.
